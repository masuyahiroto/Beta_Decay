# N=126, 125核種のβ⁻崩壊特性に関する大規模殻模型研究：半減期におけるGamow-TellerおよびFirst-Forbidden遷移の役割

**原著:** Anil Kumar, Noritaka Shimizu, Yutaka Utsuno, Cenxi Yuan, Praveen C. Srivastava  
**掲載誌:** Physical Review C **109**, 064319 (2024)  
**DOI:** 10.1103/PhysRevC.109.064319

---

## アブストラクト

本研究では、Gamow-Teller（GT）遷移とFirst-Forbidden（FF）遷移の両方を考慮した大規模殻模型計算により、Z=52–79のN=125およびN=126同中子核のβ⁻崩壊特性を調べた。GT強度分布は低励起エネルギーに顕著なピークを示し、これが半減期に大きく寄与することが観測された。このピークはν0h₉/₂→π0h₁₁/₂遷移が支配的であり、価電子陽子の0h₁₁/₂軌道占有によるPauliブロッキング効果がZ=82から陽子が減少するにつれて弱まるため、陽子欠乏側で増強される。また、FF遷移の寄与はZ=82から陽子数が減少するにつれて小さくなることが観測された。

## 研究のねらいと「良い結果」の基準（読解メモ）

> 論文本文を読む前に、「このβ崩壊計算は何を目指していて、どうなれば成功と言えるのか」を整理しておく。

### 何が出れば「良い結果」と言えるか

β崩壊計算の最終的な出力は主に次の3つの量であり、それぞれに評価基準がある。

| 出力量 | 良い結果の基準 | 本論文での実績 |
|---|---|---|
| **半減期 T₁/₂** | 実験値と同程度の桁・できれば数十%以内で一致 | log スケール偏差 r̄=−0.18, σ=0.17（実験の0.66〜1.48倍に相当） |
| **Q(β⁻) 値** | 実験値と0.5 MeV程度以内で一致（T₁/₂はQ⁵に比例して敏感なため） | 実験既知核と概ね0.5 MeV以内で一致 |
| **基底状態スピン・パリティ** | 実験で確定している値を正しく再現 | N=126は全核種で再現、N=125は202Ir, 204Auを除き再現 |

これらが同時に満たされたとき、その模型（ハミルトニアン・模型空間・クエンチング因子の組）は「この核種領域で信頼できる」と判断される。逆に言えば、**実験データが存在する核種でまず検証し、そこで合格した模型を使って実験データのない核種を予測する**、という二段階の構成になっている。

### 現在わかっていない点（本論文時点での未解決問題）

1. **N=126の陽子欠乏側（Z<78）・N=125（Z<77）の半減期は実験未測定** — 理論予測のみで、検証する手立てがまだない。
2. **超中性子過剰N=126核のQ(β⁻)値も実験未測定** — 殻模型自身の値を使うしかなく、独立検証ができない。
3. **β遅発中性子放出確率 P_n の実験データがN=126領域に存在しない** — FRDM19・KTUY05・殻模型の予測が互いに異なるが、どれが正しいか判定する実験的根拠がない。
4. **FF遷移の寄与の「減り方」が模型間で定量的に異なる**（例：Z=73→66で殻模型は82%→20%、RQRPAは90%→70%）— 同じ物理現象（陽子欠乏側でFF遷移が弱まる）を予言してはいるが、減少の度合いが模型ごとに食い違う理由は未解明（論文中で「将来の課題」と明記）。
5. **²⁰⁵Auの一部のFF遷移**（1/2⁻, 3/2⁻状態）で計算が実験を約9倍過小評価 — 原因不明。

### このβ崩壊計算で知りたい値とそのモチベーション

| 知りたい値 | 物理的な意味・モチベーション |
|---|---|
| **半減期 T₁/₂** | rプロセスが各待機点核にどれだけ長く「滞留」するかを決める。これがrプロセス全体の時間スケールと最終的な元素存在量比を左右する。 |
| **GT強度関数 B(GT) の分布（励起エネルギー依存性）** | どの一粒子遷移（ν0h₉/₂→π0h₁₁/₂等）が崩壊を支配しているかを知ることで、核構造（Pauliブロッキング、軌道占有率）への理解を半減期の数値だけでなく「理由」までセットで得られる。 |
| **FF遷移とGT遷移の相対的寄与** | どちらの遷移機構が支配的かが核種ごとに変わるため、片方だけ（GTのみ）で計算した場合にどの程度半減期がずれるかを把握する必要がある。 |
| **β遅発中性子放出確率 P_n** | rプロセス末期（フリーズアウト後）に中性子を再放出する量であり、最終的な存在量パターンの偶奇構造を滑らかにする効果を持つ。半減期と並ぶ重要な核データ。 |
| **陽子数Zに対する系統的傾向（Z=52〜79を通した変化）** | 個々の核種の値だけでなく、「陽子数が減るとどう変化するか」という**トレンド**を掴むことで、未測定核種への外挿（予測）の信頼性を高められる。 |

つまり本研究のモチベーションは、**単発の半減期の数値を当てること自体が目的ではなく**、「どの遷移機構が・どの軌道占有状況で・どう半減期を決めているか」という**物理的なメカニズムを実験で検証可能な核種について確立し、それを実験不可能な核種（rプロセス第三ピーク領域）に外挿可能な形で系統化すること**にある。

## I. 序論

β崩壊は、急速中性子捕獲過程（rプロセス）などの天体物理現象において中心的な役割を担う。rプロセスは鉄より重い元素の約半分の合成に最も重要なメカニズムであり〔1〕、比較的高温（T≈10⁹K）・高中性子密度（>10²⁰ 個/cm³）環境で起こる〔2–6〕。爆発的核合成の[rプロセス](#note-rprocess)では、[魔法中性子数N=50, 82, 126](#note-magic)での[中性子殻閉鎖](#note-closure)付近で[中性子捕獲率が急速に低下](#note-capture)し、[β崩壊が重い元素への物質移送の主要メカニズム](#note-beta)となる〔7〕。したがってrプロセスは、さらなる中性子捕獲が可能になるまで複数のβ崩壊過程を待つ必要がある。このため太陽系の[rプロセス存在量分布は、A≈80, 130, 195付近に三つの極大を示し](#note-peaks)、これらは核図表上の中性子過剰領域におけるN=50, 82, 126に対応する。これらの核種はrプロセス経路上の[**待機点核（waiting-point nuclei）**](#note-waiting)と呼ばれる。

rプロセスで生成される元素の存在量は、質量・中性子捕獲率・光分解率・β崩壊率・β遅発過程・核分裂確率など、多くの核構造インプットに強く依存する。特に待機点核でのβ崩壊過程が重要である。実験面では、N=50〔9–12〕やN=82〔13–16〕付近でβ崩壊半減期が多く測定されているが、N=126付近のrプロセス待機点核の半減期データはいまだ不足している。近年Moralesら〔17〕はGSIのRISINGプロジェクトで⁲⁰⁸Pb付近の19核種（N=125の²⁰²Ir, ²⁰³Pt, ²⁰⁴AuおよびN=126の²⁰⁴Pt, ²⁰⁵Auを含む）のβ崩壊半減期を測定した。さらに最近の研究〔18〕では、N=125, 126を含む20核種の新たな実験半減期が報告されている。N=126最重閉殻付近の新核種探索は実験的に挑戦的な課題であり続けており、新世代の放射性イオンビーム施設の整備によって今後さらなる進展が期待される〔7, 17, 19, 20〕。

A≈195付近の第三ピーク待機点核の実験情報が不足しているため、核模型による半減期の理論予測がより重要になっている。これまでにFRDM（有限距離液滴模型）〔21, 22〕、FRDM-QRPA〔23〕、HFB-QRPA〔24, 25〕、DFT-QRPA〔8, 26, 27〕などによる計算が多数行われてきた。また有限振幅法（FAM-QRPA）〔28, 29〕や機械学習〔30〕、相対論的QRPA〔31〕による研究もある。一方、N=126同中子核のβ崩壊半減期の**殻模型計算**はそれほど多くなく、初期の研究〔32, 33〕ではGT遷移のみが考慮されていた。しかしN=126付近の待機点核では**First-Forbidden（FF）遷移**の役割が半減期決定に決定的となることが指摘されており〔26〕、その後の殻模型計算〔34–36〕ではZ=64–78のN=126同中子核にGT+FF遷移を組み込んだ計算が行われたが、計算コストの制約から模型空間が制限されていた。また²⁰⁸Pb周辺核のβ崩壊特性の系統的殻模型計算〔37, 38〕も最近行われている。

本研究の目的は、Z=79からZ=52まで陽子数を変化させたN=126およびN=125同中子核のGT強度分布を系統的に明らかにすることである。陽子欠乏側でGT崩壊が加速する（価電子陽子の0h₁₁/₂軌道の空孔増加によりPauliブロッキングが弱まる）ことを示す。またFF遷移の寄与がZ=82から陽子が減少するにつれて小さくなることも明らかにする。これと同様の現象が最近N=82, 81同中子核で観測されている〔39〕。本研究ではGT遷移とFF遷移の両方を考慮した大規模殻模型計算でN=125, 126同中子核の系統的な半減期を算出し、実験データと良い一致を得た。これらのA≈195待機点核の計算結果はrプロセス第三存在量ピークの理解を深めるものである。

## II. 方法

### A. β崩壊理論

本計算ではGT遷移とFF遷移の両方を考慮した。β崩壊の形式論は文献〔40〕（BehrensおよびBühring）に詳しく確立されており、本研究では文献〔34, 35, 42〕に基づいたFF β⁻崩壊理論の簡略版を使用した。

親核の初期状態から娘核の最終状態へのβ⁻遷移の**部分半減期**は以下のように表される：

$$t_{1/2} = \frac{\kappa}{f}$$

ここで定数 κ = 6144±2 s〔27, 43〕、**位相空間因子** f は：

$$f = \int_1^{W_0} C(W)(W^2-1)^{1/2} W(W_0-W)^2 F(Z,W) \, dW$$

Wは放出電子の全エネルギー（電子質量単位）、W₀はWの最大値（Q値に対応）、F(Z,W)はFermi関数、C(W)はβ崩壊遷移の核構造情報を含む**シェイプファクター**である。

**GT遷移**のシェイプファクターは電子エネルギーに依存しない：

$$C(W) = B(\mathrm{GT}) = \frac{|M_\mathrm{GT}|^2}{2J_i+1}$$

ここで J_i は初期状態の角運動量、M_GT はGT核行列要素（表I参照）。

**FF β崩壊**のシェイプファクターは次の形をとる：

$$C(W) = K_0 + K_1 W + K_{-1}/W + K_2 W^2$$

係数 K_n（n=−1, 0, 1, 2）はFF核行列要素の関数であり、ランク0, 1, 2の各遷移に対して異なる表式をとる（詳細は文献〔35, 46〕参照）。

ここで λ = −g_A/g_V = 1.2701(25)〔44〕は軸性ベクトル結合定数と軸性結合定数の比であり、ξ = αZ/(2R)、γ₁ = [1−(αZ)²]^{1/2}（α: 微細構造定数、R: 電荷半径）。μ₁≈1、λ₂≈1〔45〕と近似する。

**Coulomb変位エネルギー** ΔE_C（実験式〔46〕）：

$$\Delta E_C = 1.4136(1)\tilde{Z}/A^{1/3} - 0.91338(11) \, \mathrm{MeV}$$

ここで $\tilde{Z} = (Z_i + Z_f)/2$。

理論と実験の比較には、**平均シェイプファクター** ⟨C(W)⟩ = f/f₀ を用いる（f₀ は B(GT)=1、GT遷移の位相空間因子）。

GT遷移とFF遷移の部分半減期 t_{1/2} を用いた**全半減期** T_{1/2}：

$$\frac{1}{T_{1/2}} = \sum_f \frac{1}{t_{i\to f}}$$

**β遅発中性子放出確率** P_n：

$$P_n = \left(\sum_{E_f \geq S_n} \frac{1}{t_{i\to f}}\right) / \left(\sum_{\mathrm{all}\,f} \frac{1}{t_{i\to f}}\right)$$

ここで S_n は一中性子分離エネルギー。

### B. 殻模型の枠組み

本研究では Z=52–79 の N=126 および N=125 同中子核のβ崩壊特性を評価するために殻模型計算を実施した。陽子軌道として 0g₇/₂, 1d₅/₂, 3s₁/₂, 1d₃/₂, 0h₁₁/₂（Z≦82）、中性子軌道として 0h₉/₂, 1f₇/₂,₅/₂, 2p₃/₂,₁/₂, 0i₁₃/₂（82≦N≦126）を用いた**一主殻模型空間**を採用した。有効ハミルトニアンには、²⁰⁸Pb芯の空孔−空孔チャンネルに基づくKuo-HerlingハミルトニアンKHHE〔47〕の微修正版を使用した。殻模型行列のM-scheme次元は最大1.33×10¹⁰に達する。

N=125の開殻核では次元がさらに大きくなるため、**モノポールに基づく切断（monopole-based truncation）**を用いた〔50, 51〕。有効単粒子エネルギー（ESPE）：

$$E_j = E_j^c + \sum_{j'} V_{m;jj'} N_{j'}$$

ここで E_j^c は j 軌道の単粒子エネルギー、V_{m;jj'} は単極相互作用の強さ、N_{j'} は j' 軌道の粒子数。パーティションの全モノポールエネルギー：

$$E_m^P = \sum_j E_j^c N_{P;j} + \sum_{j<j'} V_{m;jj'} N_{P;j}\left(N_{P;j'} + \frac{\delta_{jj'}}{2}\right)$$

本研究では Z=60–71 の N=125 同中子核の FF 遷移計算に、切断エネルギー 10 MeV のモノポール切断を適用した。

### C. 有効演算子（クエンチング）

殻模型計算を実験β崩壊率と比較するために、有効演算子を用いる。

**GT演算子**については、裸のGT演算子 σt をクエンチング因子 q で置き換えた有効演算子 $\hat{O}_\mathrm{GT}^\mathrm{eff} = q\sigma t$ を使用する〔55–57〕。クエンチング因子は、完全殻模型計算が可能な既知のβ⁻遷移（¹⁹⁹Pt(5/2⁻)→¹⁹⁹Au(7/2⁻)、²⁰⁰Auᵐ(12⁻)→²⁰⁰Hg(11⁻)）についての理論 M_GT 値の χ² 最小化により決定した（表III参照）。得られたクエンチング因子は **q = 0.54** であり、A≈200質量域の参照値 g_A^eff = 1.269 A^{-0.12} から予測される q ≈ 0.53 と良い一致を示す。

**FF演算子**については、実験的に既知の N=125, 126のFF遷移に対して、各演算子のクエンチング因子を平均シェイプファクターの χ² 最小化で個別決定した（表II参照）。

| | GT | FF (M₀ˢ) | FF (M₀ᵀ) | x | u | z |
|---|---|---|---|---|---|---|
| 本研究 | 0.54 | 0.41 | 1.266 | 0.51 | 0.28 | 0.71 |
| Zhi et al.〔35〕 | 0.66 | — | 1.266 | 0.51 | 0.38 | 0.42 |

## III. 結果

### A. モノポール切断の収束性

β崩壊半減期はGT強度とFF強度を合わせて評価される。GT強度はLanczos強度関数法〔52, 73, 74〕（250 Lanczosステップ）で計算し、N=126, 125の場合には模型空間の切断は不要である。FF強度はハミルトニアンの対角化で計算し、娘核の各スピン・パリティについて50固有状態を求めた。

N=125の開殻核ではFF遷移の計算にモノポール切断が必要となる。収束性の検証のため、FF遷移が半減期に大きく寄与する ¹⁹³Ho（N=126）、¹⁹⁶Yb（N=126）、¹⁹⁸Hf（N=126）を例として選択した（M-scheme次元はそれぞれ 5.18×10⁸、1.47×10⁸、3.36×10⁷）。

図2(b)に示すように、切断なしの正確計算との比較から、**切断エネルギー 10 MeV** で半減期の収束が得られることを確認した（N=125の Z=60–71 に適用）。FF強度のほとんどは低励起エネルギー E_x ≈ 2–3 MeV に分布するため（図3）、10 MeV の切断は十分な精度を与える。

### B. 低励起エネルギースペクトル

図4に N=126 同中子核（Z=76–81）の低励起準位を示す。基底状態のスピン・パリティは使用した相互作用でいずれも正しく再現された。図5に N=125 同中子核の準位を示す。²⁰²Ir と ²⁰⁴Au を除いてほぼ正しく再現されているが、²⁰²Ir の基底状態の実験的確認がないこと、²⁰⁴Au では理論予測(0⁻)と実験(2⁻)が逆転している（ただし10 keVしか離れていない）ことに注意する。

### C. N=125およびN=126同中子核の半減期

計算のための Q(β⁻) 値は殻模型の枠組みから導出した（図6）。殻模型の Q(β⁻) 値はZ=82付近の実験値（Z=76–80）と典型誤差0.5 MeV以内で良い一致を示し、FRDM19・KTUY05の傾向とも整合する。

|---|---|---|---|
| ²⁰²Ir | 4.7 s | 15(3) s | — |
| ²⁰³Pt | 20.6 s | 22(4) s | — |
| ²⁰⁴Au | 25.4 s | 37.2(8) s | — |
| ²⁰⁴Pt | 13.9 s | 16⁺⁶₋₅ s | 38.3 s |

²⁰⁴Pt の半減期が先行研究〔36〕の38.3 s から本研究の13.9 s に短縮された主な理由は、①修正 KHHE ハミルトニアンによるやや大きな Q(β⁻) 値、②FF演算子の個別クエンチング因子の採用、③完全模型空間での計算、の三点である。

図7に Z=52–79 の N=126, 125 同中子核の理論半減期を示す。殻模型はFRDM19に見られる Z>70 での強い奇偶スタガリングを予測しないが、実験値の傾向を定性的に再現する。

**FF遷移の寄与（図10）**：
- N=126: Z≳70 で FF 遷移が支配的（~82% at Z=73）、Z≲66 では 20% 未満
- N=125: Z≳72 で FF 遷移が支配的
- FF 遷移の寄与は Z=82 に近づくにつれ増加（Z=53 の約3%から Z=79 の約100%まで）
- 本研究の FF 寄与の減少はRQRPA〔27〕よりも強く、陽子欠乏側で smaller FF 寄与を予測する

**β遅発中性子放出確率 P_n（図11）**：
- Z≲60 では P_n ≈ 100%（小さな中性子分離エネルギーと大きな Q 値のため）
- Z=62–76 では P_n が急落し、強い奇偶スタガリングが現れる
- FRDM19 は本研究と類似の傾向、KTUY05 はより小さな値を予測

### D. Gamow-Teller強度関数

GT強度関数の最も重要な観測結果は二つある：

**1. 低励起エネルギーへの GT 強度集中**

N=126 同中子核では GT 強度ピークが低励起エネルギー（偶 Z では 3–6 MeV、奇 Z では 5–7 MeV）に観測される。奇 Z で若干高いエネルギーにピークが現れるのは、娘核のペアリング相関に起因する。N=125 では N=126 より若干高い励起エネルギーにピークが移動する（図12, 13）。

**2. 陽子数減少に伴うGT強度の増強（Pauliブロッキング効果の減弱）**

GT強度ピークは Z=79 から Z=52 に向けて系統的に増強される。これは主要な GT 遷移 ν0h₉/₂→π0h₁₁/₂ に対する Pauli ブロッキング効果が、π0h₁₁/₂ 軌道の空孔増加とともに弱まることによる（図14）。Z≈71 を境に π0h₁₁/₂ 軌道占有率が急変し、Z≲71 では Pauli ブロッキングが大幅に弱まりGT強度が増大する。

**GTピークエネルギーの解釈**（Z=52, N=126を例に）：

簡単な単粒子描像では、GT強度ピークエネルギーは
- ν0h₉/₂ の ESPE（Fermi面から約-2.6 MeV）
- π0h₁₁/₂ の ESPE（Fermi面から約+1.6 MeV）
- 粒子-空孔行列要素 ⟨π0h₁₁/₂(ν0h₉/₂)⁻¹|V|π0h₁₁/₂(ν0h₉/₂)⁻¹⟩_{J=1}（約+1.0 MeV）

の和として ≈5.2 MeV と見積もられ、殻模型の結果と一致する（図16）。Z=82 に近い核種では空孔-空孔行列要素が支配的となる。

**ESPE の変化（図15）**：

Z=82 から Z=70 では π0h₁₁/₂ 軌道の占有率が変化する。Z≳71 では π0h₁₁/₂ が 85% 以上占有されており、Z=70–82 の領域では 2s₁/₂ と 1d₃/₂,₅/₂ 軌道が最低非占有軌道となる。FF 遷移は ν(0i₁₃/₂)→π(0h₁₁/₂)、ν(0h₉/₂)→π(0g₇/₂)、ν(fp)→π(sd) で接続されるが、2s₁/₂ や 1d₃/₂ 軌道の空き（それぞれ約12%、35%）のため、ν(fp)→π(sd) の FF 遷移が Z≳70 側で重要になる。

## IV. まとめ

Z=52–79 の N=126 および N=125 同中子核の核β崩壊特性（半減期およびβ遅発中性子放出確率）を調べた。修正 KHHE ハミルトニアンを用いた**一主殻模型空間での大規模殻模型計算**を実施した。

主要な結論：

1. **有効相互作用の妥当性**：N=126, 125 核種の低励起準位スペクトルおよび Q(β⁻) 値が実験データをよく再現することを示した。

2. **モノポール切断の有効性**：N=125 開殻核の FF 遷移計算への 10 MeV モノポール切断適用で良好な収束を確認した。大規模殻模型計算の実現可能性を示した。

3. **FF遷移の重要性**：Z≳70（N=126, 125 同中子核）では First-Forbidden 遷移が半減期を短縮する。これらの同中子核の全半減期評価に FF 遷移の組み込みが不可欠である。

4. **Gamow-Teller強度の増強**：Z≲70 の陽子欠乏側では GT 遷移が半減期を支配する。価電子陽子 0h₁₁/₂ 軌道の空孔増加による Pauli ブロッキング効果の弱化により、GT 強度が Z=79 から Z=52 にかけて系統的に増大する。

5. **実験的予言**：Z<78（N=126）および Z<77（N=125）の実験未知β崩壊の半減期を理論予測し、今後の実験に向けた指針を提供した。β崩壊半減期とβ遅発中性子放出確率の系統的情報は、rプロセス核合成の理解に大きく貢献する。

<a id="note-rprocess"></a>
### rプロセス（rapid neutron-capture process：急速中性子捕獲過程）とは

**一言で言うと**：中性子を次々と高速で捕まえながら重い元素を作る核反応の連鎖。

通常の星内部（sプロセス）では中性子捕獲がゆっくり（slow）起こり、捕獲した中性子が不安定なら β 崩壊して安定核に戻ってから次の捕獲が起こる。一方 rプロセスでは、中性子密度が極めて高い（>10²⁰ 個/cm³）ため、β 崩壊が起こる前に次々と中性子を捕獲し続ける。

```
(Z, A) --中性子捕獲--> (Z, A+1) --中性子捕獲--> (Z, A+2) --> ...
                                                       ↓ (中性子過剰になりすぎて限界)
                                                    β崩壊
                                                       ↓
                                                  (Z+1, A+2)
```

こうして陽子数が増えていき（鉄から）金・白金・ウランなど鉄より重い重元素が生成される。rプロセスは中性子星合体や超新星爆発で起こると考えられている。

<a id="note-magic"></a>
### 魔法数（magic number）とは

**一言で言うと**：陽子または中性子がこの数だと核が特に安定になる「特別な粒子数」。

原子核の中では陽子・中性子がそれぞれ「殻（shell）」と呼ばれるエネルギー準位を埋めていく（電子の軌道と同じ考え方）。ある殻が完全に満たされたとき（殻閉鎖）、核は特に強く束縛され安定になる。

その粒子数が**魔法数**：

| 魔法数 | 対応する閉殻軌道（中性子の場合） |
|---|---|
| 2 | 1s₁/₂ |
| 8 | 1p₃/₂, 1p₁/₂ |
| 20 | 1d₅/₂, 2s₁/₂, 1d₃/₂ |
| 28 | 1f₇/₂ |
| 50 | 2p, 1f₅/₂, 1g₉/₂ |
| 82 | 1g₇/₂, 2d, 3s₁/₂, 1h₁₁/₂ |
| **126** | 1h₉/₂, 2f, 3p, 0i₁₃/₂ |

本論文では N=126（²⁰⁸Pb の閉殻）付近の核種を扱っている。魔法数の核は分離エネルギーが大きく、β 崩壊の Q 値が小さくなるため半減期が長くなる傾向がある。

<a id="note-closure"></a>
### 中性子殻閉鎖（neutron shell closure）とは

**一言で言うと**：中性子が魔法数だけ詰まって殻が完全に満たされた状態。

殻が閉じると（例：N=126）、その直上の軌道に中性子を加えるためには大きなエネルギーが必要になる。これを「閉殻による安定化」という。

```
エネルギー
  ↑  ---- 次の殻（空）
  |   ← 大きなギャップ（殻間エネルギー差）
  |  XXXXXXXXXX  N=126で完全に埋まった殻
  |  XXXXXXXXXX
  |  ......
```

N=126 では ²⁰⁸Pb が二重魔法核（陽子 Z=82、中性子 N=126）であり、特に安定。この閉殻構造が中性子捕獲率の低下と深く関係している。

<a id="note-capture"></a>
### 殻閉鎖付近で中性子捕獲率が急速に低下する理由

rプロセスでは、「中性子捕獲」と「光分解（逆反応）」がほぼ平衡した状態で経路が決まる（(n,γ)–(γ,n) 平衡）。

N=126 の閉殻付近では次の二つの効果が重なる：

1. **分離エネルギーの増大**：殻が閉じると次の中性子を加えるのに必要なエネルギーが大きくなる。逆に言えば、付け加えた中性子が光分解（γ 線で中性子を叩き出す反応）されやすくなる。
2. **捕獲断面積の減少**：閉殻核は球形で安定なため、中性子と反応しにくい（共鳴準位の密度が低い）。

その結果、rプロセスの経路は **N=126 付近で「詰まる」**（捕獲より崩壊が速くなる）。この「渋滞」がrプロセスを一時停止させる。

<a id="note-beta"></a>
### β崩壊がなぜ「重い元素への物質移送」になるか

rプロセスでは中性子を捕獲するほど核は中性子過剰になっていくが、**陽子数（Z）は増えない**。より重い元素（原子番号が大きい元素）になるには **陽子数を増やす**必要がある。

β⁻崩壊では：

```
n → p + e⁻ + ν̄ₑ
```

すなわち **中性子が陽子に変わる（Zが1増える）**。殻閉鎖で中性子捕獲が止まったとき、β崩壊が続くことで核の陽子数が増加し、rプロセスの流れが再び重い元素側へ進む。

```
rプロセスの流れ（模式図）：
(Z, N=126) --β崩壊--> (Z+1, N=125) --β崩壊--> (Z+2, N=124) --> ...
              ↑ここで中性子捕獲が再開できる状況になったら
              次のサイクルへ
```

<a id="note-capture-beta-link"></a>
### 補足：「中性子捕獲が止まること」と「β崩壊」はどうつながっているか

[#note-capture](#note-capture) と [#note-beta](#note-beta) は別々に説明したが、実際には一つの**時間スケールの競争**として理解するとつながりが見える。

核がたどる経路は、その瞬間に「中性子捕獲」と「β崩壊」のどちらが**速く起こるか**で決まる。

```
中性子捕獲にかかる時間 τ_capture  vs  β崩壊にかかる時間 τ_β(=半減期T₁/₂)
```

- **殻閉鎖から離れた核**：中性子分離エネルギーが大きく、中性子を吸収しやすい → τ_capture が非常に短い（β崩壊よりずっと速い）。したがって核は β崩壊を待たずに次々と中性子を吸収し、中性子過剰側へどんどん進む。
- **殻閉鎖（N=126等）に達した核**：[#note-capture](#note-capture) で述べた理由（分離エネルギー増大・断面積減少）により τ_capture が急激に長くなる。一方 τ_β（半減期）はそこまで変化しない。その結果、**τ_β < τ_capture となり、β崩壊が中性子捕獲より先に起こるようになる**。

つまり「中性子捕獲が止まる」とは、正確には「止まる」のではなく「β崩壊より遅くなる」ということ。この**逆転が起きた瞬間に、核の進む方向が変わる**：

```
殻閉鎖前: 中性子捕獲が支配的 → N がどんどん増える（Zは一定）
            ↓ τ_capture が τ_β を超える（殻閉鎖到達）
殻閉鎖時: β崩壊が支配的 → Z が1増え、Nが1減る（β崩壊後）
            ↓ Z が増えたことで中性子分離エネルギーが変化
殻閉鎖後: 中性子分離エネルギーが回復し、再び中性子捕獲が支配的に戻る
```

この「β崩壊待ちの期間」こそが [#note-waiting](#note-waiting) で説明する待機点核の本質であり、**その待ち時間（=半減期 T₁/₂）の長さが、rプロセス全体がその質量数領域に留まる時間を決める**。本論文がN=126, 125核種の半減期を精密に計算しようとしているのは、まさにこの「待ち時間」を正確に求めることがrプロセスの時間進行を理解する鍵になるためである。

<a id="note-waiting"></a>
### 待機点核（waiting-point nuclei）とは

**一言で言うと**：rプロセスが殻閉鎖で詰まり、β崩壊を何度も「待つ」羽目になる核種群。

rプロセスは大量の中性子を高速で捕獲しながら進むが、魔法数 N=50, 82, 126 の殻閉鎖に達すると中性子捕獲が事実上止まる。そこで **β崩壊が終わるのを「待つ」**しかなく、この核種が「waiting point（待機点）」と呼ばれる。

```
待機点のイメージ：
        ↓ 中性子捕獲が止まる
[Z, N=126] → β崩壊待ち（T₁/₂ が重要！）
        ↓ β崩壊後
[Z+1, N=125] → また中性子捕獲できる？ or また待機？
```

半減期 T₁/₂ が **rプロセスの速度（タイムスケール）**を直接決めるため、本論文はこれらの核種の半減期を精密に計算することを目的としている。

<a id="note-peaks"></a>
### rプロセス存在量分布の「三つの極大」が現れる理由

太陽系の元素存在量を質量数 A に対してプロットすると、**A≈80, 130, 195** 付近に山（ピーク）が現れる。これが rプロセスの三つのピークである。

**なぜ三カ所にピークが現れるか：**

rプロセスの流れは「中性子捕獲で重くなる → 殻閉鎖で止まる → β崩壊でZ増加 → また捕獲」を繰り返す。閉殻（N=50, 82, 126）では物質の流れが**渋滞**する。その結果、これらの閉殻を経由した後に安定核に落ち着く質量数付近に核が大量に蓄積する：

| 殻閉鎖 | 中性子過剰rプロセス経路 | β崩壊後の安定核付近 | 観測ピーク |
|---|---|---|---|
| N=50 | A≈80 の中性子過剰核 | A≈80 付近の安定核 | **A≈80ピーク** |
| N=82 | A≈130 の中性子過剰核 | A≈130 付近の安定核 | **A≈130ピーク** |
| N=126 | A≈195 の中性子過剰核 | A≈195 付近（Pt, Au, Hg...） | **A≈195ピーク** |

本論文が対象とするのは**第三ピーク（A≈195, N=126）付近**の核種であり、ここの半減期が不明確なためにrプロセスの第三ピーク形成の理論計算に大きな不確かさがある。
